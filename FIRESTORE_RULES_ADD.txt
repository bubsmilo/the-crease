The Crease v8.6.194 — FIRESTORE RULES ADDITION

IMPORTANT: Do NOT replace your existing Firestore rules. In Firebase Console > Firestore Database > Rules, locate the existing block:

    match /teams/{teamId} {

Inside that block, immediately after the existing match /games/{docId} or match /goalies/{docId} block, add the three blocks below. Keep them nested inside /teams/{teamId}. They use your EXISTING isMember(teamId) and canEdit(teamId) helper functions.

    match /leagueScores/{docId} {
      allow read: if isMember(teamId);
      allow create, update: if canEdit(teamId)
        && request.resource.data.keys().hasAll(['hs', 'as', 'home', 'away', 'date', 'owha'])
        && ( (request.resource.data.hs == null && request.resource.data.as == null)
          || (request.resource.data.hs is int && request.resource.data.as is int
              && request.resource.data.hs >= 0 && request.resource.data.as >= 0) );
      allow delete: if false;
    }

    match /leagueLinks/{docId} {
      allow read: if isMember(teamId);
      allow create, update: if canEdit(teamId)
        && request.resource.data.opponent is string
        && request.resource.data.teamName is string;
      allow delete: if false;
    }

    match /leaguePredictions/{docId} {
      allow read: if isMember(teamId);
      allow create: if canEdit(teamId)
        && request.resource.data.gameId is int
        && request.resource.data.predA is int
        && request.resource.data.predB is int
        && request.resource.data.savedAt is string;
      allow update: if false; // freeze forecasts once saved
      allow delete: if canEdit(teamId);
    }

Click Publish only after saving a backup of your existing rules. These rules do not modify existing /games, /goalies or other collections.
