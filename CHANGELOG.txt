v8.6.120 — SMALL RECAP CARD GAME LINK FIX
============================================================
FIXED
- The Last Game / small recap card now stores the exact saved game's Firebase/local game ID when it is rendered.
- Clicking the small recap card looks up that exact game ID and opens its full scorecard.
- It no longer relies on games[0] at click time.
- This makes the small recap card and its full game recap directly linked even if game ordering/rendering changes.
- Keeps the workload-coloured full scorecard from v8.6.118/v8.6.119.

TEST
1. Refresh and confirm the browser tab says The Crease v8.6.120.

3. Click the card.

5. Confirm Games-history cards still open normally.

============================================================
v8.6.119 — RECAP CARD → FULL SCORECARD FIX
============================================================
FIXED
- Fixed a regression introduced in v8.6.118 that could stop a saved-game recap card from opening the full scorecard.
- The click binding itself was still present.
- The failure happened while opening the scorecard because the new workload-colour code called a helper that only exists inside the Stats screen.
- The scorecard now uses the app's global gameIntensity() logic directly.
- Small recap cards / saved-game cards should once again open the correct full scorecard.
- Keeps the v8.6.118 workload-coloured full scorecard behavior.

============================================================
v8.6.118 — FULL SCORECARD WORKLOAD COLOURS
============================================================
CHANGED
- The full/opened game scorecard now uses workload colour rather than Win/Loss/Tie colour.
- Light = green.
- Moderate = yellow.
- Busy = orange.
- Under Siege = red.
- Win/Loss/Tie remains clearly displayed as the game result.
- A light-workload loss can therefore remain green when opened instead of turning red.
- Browser title updated to v8.6.118.
- Service-worker cache bumped.

============================================================
v8.6.117 — GAME RESULT BADGES / WORKLOAD SEPARATION
============================================================
CHANGED
- Kept workload colour as the meaning of the condensed Games card colour/glow.
- Separated game result from workload.
- Win displays W ✓.
- Loss displays L ×.
- Tie displays T =.
- Result badge uses a neutral nightclub-style treatment so red/green does not compete with workload meaning.
- Browser title/cache updated for the release.

v8.6.116 — PLAYER OF THE GAME + ACHIEVEMENTS + GAME ORDER
============================================================
CHANGED
- Games history ordered newest to oldest.
