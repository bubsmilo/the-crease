THE CREASE — v8.6.116
Release date: September 27, 2026

PURPOSE OF THIS VERSION
This release improves the Games history and turns Player of the Game into a trackable accomplishment.

CHANGES
1. NEWEST GAMES FIRST
- Games are ordered newest to oldest.
- Month groups are ordered newest to oldest.
- The newest month is expanded by default.
- Older month groups are collapsed.
- Within each month, the newest game appears first.

2. PLAYER OF THE GAME BUTTON
- Player of the Game remains stored on the individual saved game.
- The selected/active state is made much more obvious with a gold appearance and check mark.
- The selection persists with the saved game so it can be seen again when the game is reopened.

3. PLAYER OF THE GAME TRACKING + ACHIEVEMENTS
- Player of the Game awards are counted from completed games.
- Existing games marked Player of the Game count toward the player's total.
- Added achievement milestones:
  • First Star — 1 Player of the Game award
  • Game Star — 5 Player of the Game awards
  • Team Standout — 10 Player of the Game awards
- The underlying count continues beyond these milestones so more achievements can be added later.

4. CLEANUP
- Removed the outdated Player of the Game “Coming Soon” placeholder from Settings.

5. VERSION / RELEASE IDENTIFICATION
- Browser title updated to The Crease v8.6.116.
- This ZIP uses a descriptive filename so its purpose is recognizable later.
- A changelog is included in the ZIP for future reference.

TEST AFTER DEPLOYING
- Refresh the app and confirm the browser tab says The Crease v8.6.116.
- Open an existing saved game.
- Press Player of the Game and confirm the button visibly activates.
- Close and reopen that game and confirm the selection remains.
- Check Achievements and confirm the Player of the Game count/progress appears.
- Check Games and confirm the newest month and newest games are at the top.
